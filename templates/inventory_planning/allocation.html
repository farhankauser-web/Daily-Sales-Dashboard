1 · Container & packing list

Expects SKU, Supplier and Units (or Box × P/Box), with an optional PO Number column — the template has dropdowns for all three. One file describes the whole container, so a container loaded from two factories is one upload with each row naming its own supplier. With a PO number the match is exact; without one, units draw FIFO from that row's supplier's oldest open Production Plan — check the PO shown on each line before confirming. Re-uploading a container number replaces its lines, so always send the complete packing list.
