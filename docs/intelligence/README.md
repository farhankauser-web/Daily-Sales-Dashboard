# Intelligence

The layer that reads everything else and says what needs attention: profit
alerts, AI recommendations, the morning report and the executive summary.

## Purpose

Six sections each hold their own numbers, and nobody reads six sections every
morning. This one exists to answer a single question — **what changed, and does
it need me?** — and to hand the reader straight to the section that explains it.

Like the Command Center, it is deliberately **a reader, not a source**. Every
figure it surfaces belongs to another domain.

**This section is complete and frozen** except for future feature changes. Two
features are documented; the process lessons are in
[RETROSPECTIVE.md](RETROSPECTIVE.md).

## Data source

| Source | Grain | Authoritative for |
|---|---|---|
| Every other section's figures | as each stores them | the underlying facts |
| Anthropic API | per request | the narrative wording only, never a number |

**The AI layer writes prose, not figures.** Every number it mentions is computed
before the prompt is built and passed in; the model summarises and never
calculates. See `INT-D-001`.
